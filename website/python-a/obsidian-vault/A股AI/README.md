# A 股 AI 长期记忆库

这个目录是本项目默认的 Obsidian vault。

后端主要写入路径：

```text
股票/{股票代码}-{股票名称}.md
操作记录/{日期}-{股票代码}-{股票名称}.md
每日复盘/{日期}-交易复盘.md
交易心得总纲.md
知识图谱/行业/
知识图谱/概念/
知识图谱/技术形态/
知识图谱/风险模式/
知识图谱/交易错误/
知识图谱/观察计划/
data/
```

当你在研究台保存单股分析或交易复盘时，系统会自动生成 Obsidian Markdown、双链节点和本地 JSON 账本，并写入本目录。详细结构以 `website/python-a/README.md` 为准。
