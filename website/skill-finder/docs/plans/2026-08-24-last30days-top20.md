# last30days Top 20 榜单实施计划

> **For agentic workers:** 按任务顺序执行；每个任务结束运行对应测试。Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `/last30days` 模块从自由查询研究台改造成 Agent / Skill 两个方向的"近 30 天最热 Top 20"榜单（手动刷新 + 结果存库缓存 + 主页风格呈现）。

**Architecture:** 后端新增 `last30days_reports` 表缓存每方向最新榜单；`GET /rankings` 读缓存、`POST /rankings/refresh` 同步跑引擎并按互动量取 Top 20 后 upsert。前端重写 `Last30DaysView.vue` 为 tab + 排名卡片列表，复用 `StatePanel`。

**Tech Stack:** FastAPI / SQLAlchemy 2 异步 / MySQL；Vue 3 + TS / Vitest / Playwright。

**Spec:** `docs/specs/2026-08-24-last30days-top20-design.md`

## Global Constraints

- schema.sql 保持 MySQL 5.5 兼容语法；应用绝不自动建表/改表。
- JSON 一律经 `JsonText`（Text 列）存取；新表 `payload` 列在 DDL 中用 `MEDIUMTEXT`。
- 时间存 naive UTC（`DATETIME`），返回前端时转 ISO 字符串。
- 后端代码过 `ruff check`；前端过 `eslint` + `vue-tsc`。
- 不做 git commit（本环境约定：除非用户明确要求）。
- 前端 axios 默认超时 15s；**refresh 调用必须单独设置 `timeout: 620_000`**（后端引擎超时 600s + 余量）。

- [ ] **Step 3: 新建 `app/repositories/last30days_reports.py`**（风格对齐 `collection_runs.py`）

```python
class Last30DaysReportStore:
    def __init__(self, session: AsyncSession) -> None:
        self._session = session

    async def get(self, direction: str) -> Last30DaysReport | None:
        result = await self._session.execute(
            select(Last30DaysReport).where(Last30DaysReport.direction == direction)
        )
        return result.scalar_one_or_none()

    async def upsert(self, *, direction, status, payload, message, fetched_at) -> None:
        report = await self.get(direction)
        if report is None:
            report = Last30DaysReport(direction=direction, status=status, payload=payload,
                                      message=message, fetched_at=fetched_at)
            self._session.add(report)
        else:
            report.status = status
            report.payload = payload
            report.message = message
            report.fetched_at = fetched_at
        await self._session.flush()
```

- [ ] **Step 3: 实现 service**：

```python
Direction = Literal["agent", "skill"]
DIRECTION_QUERIES: dict[str, str] = {"agent": "AI agents", "skill": "AI agent skills"}
TOP_RANK_LIMIT = 20
_direction_locks: dict[str, asyncio.Lock] = {}

def _engagement_total(engagement: Any) -> float:
    if not isinstance(engagement, dict):
        return 0.0
    return float(sum(v for v in engagement.values()
                     if isinstance(v, (int, float)) and not isinstance(v, bool)))

def rank_items(items: list[Any], limit: int = TOP_RANK_LIMIT) -> list[dict[str, Any]]:
    valid = [item for item in items if isinstance(item, dict)]
    return sorted(valid, key=lambda i: _engagement_total(i.get("engagement")), reverse=True)[:limit]
```

  - `refresh_ranking`：`settings.last30days_enabled` 为假 → skipped 空榜单；`async with _direction_locks.setdefault(direction, asyncio.Lock())`；调用 `fetch_last30days(query=DIRECTION_QUERIES[direction], limit=100)`；状态属 `{unconfigured, error, skipped}` → 不写库直接返回；否则 `rank_items` 取 Top 20，payload 含 `items/clusters/sources/source_status`，`upsert` + `session.commit()`；`SQLAlchemyError` → `session.rollback()` 并返回 error（提示先执行最新 schema.sql）。
  - `get_ranking`：`store.get` 异常 → 空态 + 初始化提示；无记录 → `no-results` 空态（"该方向还没有榜单数据，点击刷新按钮生成。"）；有记录 → 组装响应。
  - fetched_at：入库前 `datetime.fromisoformat(s)` → `astimezone(UTC).replace(tzinfo=None)`；出库 `replace(tzinfo=UTC).isoformat()`。
