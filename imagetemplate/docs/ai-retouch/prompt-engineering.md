# AI 修图提示词工程手册

> 目标：让你靠「AI + 提示词」完成绝大多数客户需求。
> 本文是**方法论与句式模板**；分场景的交付规格与完整模板见后续 `prompt-library.md`。

---

## 一、最重要的认知：修图提示词 ≠ 文生图提示词

这是 90% 的人踩的第一个坑。两者是**完全不同的写作范式**：

| | 文生图（Text-to-Image） | 修图 / 图像编辑（Image Editing） |
|---|---|---|
| 目标 | **无中生有**，描述你想要什么 | **最小改动**，描述要改什么、要保留什么 |
| 提示词结构 | 主体 + 光线 + 镜头 + 风格 + 画质词堆叠 | **改动指令 + 保留清单 + 约束** |
| 长度 | 长，形容词越多越好 | **短，越精确越好** |
| 失败模式 | 画得不像、构图差 | **改太多**、把不该动的地方也动了 |
| 忌讳 | 描述不足 | **风格词堆叠**（会引发整图重绘 → 违和感） |

**核心原则：修图提示词里加"电影感、大师作品、8K、超写实"这类风格词，会直接导致模型整图重绘，皮肤变塑料、身份漂移。** 这是违和感最常见的操作级原因。

---

## 二、修图提示词的四段式结构

```
【动作】只改什么        —— 一个明确、单一的动作
【位置】改哪里          —— 具体部位/区域，越具体越好
【程度】改成什么样      —— 带程度限定词（轻微/略微/局部）
【保留】不要动什么      —— 显式列出禁止修改的内容 ★ 最容易被忽略、却最有效
```

### 反面 / 正面示例

**❌ 错误写法**（会整图重绘，必然违和）：
> 一个美丽的女孩，皮肤白皙细腻，电影感光线，8K超高清，大师作品，梦幻氛围

**✅ 正确写法**（局部修改，不违和）：
> 只去除脸颊和额头上的痘印与红点，保持皮肤原有的毛孔纹理与质感不变。
> 保持五官形状、脸型、发型、光影方向、背景全部不变。
> 程度：轻微，不要磨皮，不要改变肤色。

## 三、"保持其余不变"的句式库（直接复制用）

这是修图提示词里**性价比最高的一句话**。显式列出"不要改"比只说"改什么"有效得多。

### 通用保留清单（照抄）
```
保持以下内容完全不变：
- 五官形状、脸型轮廓、眼睛大小与瞳孔位置
- 肤色与肤质纹理（毛孔、绒毛）
- 发型、发际线、发丝走向
- 光影方向、明暗对比、阴影位置
- 背景、构图、服装、配饰
- 画面整体的色温与色调
不要重新生成整张图片，只修改上述指定区域。
```

### 身份保持（防"不像本人"，人像场景必加）
```
这是一张真实人物的照片，请严格保持人物的身份特征：
- 保留其独特的面部比例与骨相，不要美化成通用模板脸
- 不要改变眼睛形状、鼻型、唇形、下颌线
- 目标是"同一人更好看的状态"，不是"另一个人"
```

### 局部修改（防止波及周围）
```
仅修改[目标区域]，该区域以外的所有像素保持原样。
修改区域的边缘需自然过渡，不要产生明显的边界或光晕。
```

### 反向约束（负面清单，通用）
```
避免：过度磨皮、塑料感、蜡像感、过度锐化、HDR感、
过度饱和、对称性过强、AI感、面部结构改变、多余的手指或肢体、
文字乱码、饰品结构错误。
```

## 四、按 moden 分类的写法要点

不同模型对提示词的"理解方式"不同，写法要适配：

| 模型类型 | 代表 | 写法要点 |
|---|---|---|
| **指令式编辑模型** | Gemini 3 Pro Image、FLUX Kontext、Qwen-Image-Edit、Seedream | 用自然语言**陈述句**，像给修图师下brief；明确"只改X"；支持"把A换成B"这类语义操作 |
| **对话式多轮模型** | 腾讯混元（ChatId 多轮） | 可以**分步迭代**："先去掉痘印"→"再把背景换成浅灰"→"整体稍微提亮"。比一次说完更可控 |
| **带 mask 的模型** | gpt-image-2.5、FLUX Fill | **mask 才是主要控制手段**，提示词只需极简描述（"去除"、"替换为浅灰色"） |
| **文生图模型** | Midjourney、SD、FLUX 文生图 | 才需要用完整描述 + 风格词堆叠。**不要用于修图** |

### 多轮迭代策略（推荐）
不要试图一句话完成复杂修图。**拆成串行的小步骤**，每步只做一件事：

```
第1轮：只去除痘印和斑点，其余完全不动
第2轮：在此基础上，轻微减弱眼袋，程度轻，不要改变眼型
第3轮：背景换成纯净浅灰色，人物边缘保持自然，头发发丝保留
第4轮：整体统一到参考图的暖色调
```

**好处**：每步可检查、可回退，出问题能定位是哪一步导致的。

## 五、分场景提示词模板

### 5.1 人像精修（磨皮祛痘）

**基础版**
```
只去除面部明显痘印、红点和斑点。保留皮肤真实的毛孔纹理与质感。
轻微减弱法令纹，程度要轻，不要改变脸型与五官。
保持：五官形状、脸型、发型、光影方向、背景、肤色完全不变。
避免：塑料感、蜡像感、过度磨皮、过度锐化。
```

**进阶版（分区处理，效果更自然）**
```
按区域分别处理，不要全局磨皮：
- 额头与脸颊：去除痘印，保留毛孔纹理
- 眼下：轻微减淡黑眼圈，保留卧蚕与眼袋自然结构
- 鼻翼：轻微减弱红血丝，保留鼻部皮肤质感
- 皮肤整体：保持原有肤色的冷暖倾向，不要统一漂白
不要动：眼睛、眉毛、嘴唇形状，发际线，下颌线。
```

### 5.2 老照片修复

**关键原则：修复 ≠ 重新生成。** 必须保留原片的年代感与人物特征。
```
修复这张老照片的以下问题，同时严格保留照片的历史质感：
1. 去除划痕、折痕、霉斑与污渍
2. 轻微提升清晰度，但不要过度锐化
3. 修复破损缺失区域，修补需与周围质感一致
必须保留：
- 人物原本的面部特征与神态（不要美化成现代审美）
- 原片的颗粒感与年代质感
- 原有的服装、背景、构图
- 原有的黑白/泛黄色调（除非我另行要求上色）
避免：现代滤镜感、过度平滑、脸部变形。
```

**上色专用**
```
为这张黑白老照片上色。要求：
- 肤色使用符合年代与地域特征的自然色调，不要过白
- 服装与背景颜色参考[年代]的常见配色，低饱和
- 保持照片原有的颗粒质感与光影关系
- 不要改变任何人物特征、表情与构图
避免：色彩过于鲜艳饱和、现代数码感。
```

### 5.3 证件照

**证件照是硬规格场景，提示词要配合确定性的几何处理。**
```
基于这张照片制作证件照：
- 背景替换为纯[白/蓝/红]色，颜色均匀无渐变
- 人物居中，头部占画面约 2/3，头顶留适当空白
- 正脸、双肩齐平、表情自然中性
- 服装整洁，建议深色有领
严格保持：五官形状与比例、脸型、发型（露出双耳与额头）、肤色。
禁止：瘦脸、放大眼睛、改变五官、美颜过度。
```

> ⚠️ 证件照建议：**AI 只做换底与调整，裁剪与排版用确定性代码完成**（尺寸必须精确，AI 输出尺寸不可靠）。具体要求见后续交付标准文档。

### 5.4 换背景

```
把背景替换为[描述：纯净浅灰色影棚背景 / 简约室内场景 / 户外自然光环境]。
要求：
- 保留人物头发发丝的细节与半透明边缘，不要出现硬边或白边
- 新背景的光线方向需与人物原有光线一致（主光来自[左/右/正]上方）
- 人物边缘与新背景的融合要自然，可加入适当的接触阴影
- 背景的颗粒感与人物保持一致
保持人物本身完全不变：五官、服装、姿态、肤色。
```

> ★ **光影一致性是换背景违和感的第一来源**。务必写明新背景的光位要与人物原光位匹配。

### 5.5 换装

```
把人物的[上衣/整套服装]更换为[描述：米白色针织衫 / 深色西装]。
要求：
- 服装的版型需贴合人物原有体型，自然产生褶皱
- 保持人物的面部、发型、姿态、双手位置完全不变
- 光线在服装上的明暗关系需与人物原有光照一致
- 服装边缘与身体的接触要自然（领口、袖口、下摆）
避免：改变脸型、改变身材比例、多出手指、服装结构错误。
```

### 5.6 电商产品图

```
[动作：把产品背景替换为纯白 / 加入场景元素]
要求：
- 产品本身的颜色、材质、logo、文字、比例必须完全不变（这是最关键约束）
- 新背景光线需在产品上产生合理的高光与阴影
- 产品边缘干净，可保留自然投影
- 若是纯白底，用 RGB(255,255,255)，产品边缘不要有灰边
禁止：改变产品形状、重新生成logo或文字、改变产品颜色。
```

> ★ **产品 logo 与包装文字属于"像素级不可漂移"内容**。若模型改动它们，必须改用 mask 局部处理，或先用确定性方式保护该区域。

### 5.7 婚纱照风格化

```
将这张照片处理为[风格描述]风格，保留真实照片的质感：
- 色调：奶油色系 / 低饱和 / 胶片感 [选一]
- 轻微提升皮肤通透度，保留皮肤纹理
保持：人物面部特征与身份、构图、姿态、服装结构完全不变。
避免：过度美化、改变五官、塑料感、AI绘画感。
```

> ⚠️ **婚纱照严禁整图重绘**。这是客户投诉"假"的重灾区。应走"实拍底片 + 调色 + 局部精修"路线。

## 六、常见失败模式的提示词级对策

| 现象 | 提示词级对策 |
|---|---|
| 皮肤变塑料 | 加"保留毛孔纹理"；去掉所有"细腻/光滑/无瑕"；降强度；降 denoise |
| 不像本人 | 加完整身份保持清单；去掉"美颜/精致/网红"类词；考虑用身份注入技术 |
| 背景改了但光影不对 | 显式指定新背景的光位；或改用 IC-Light 重打光 |
| 只想去痘印结果整张脸变了 | 加"仅修改指定区域，其余像素保持原样"；缩小 mask；降 denoise |
| 抠图边缘发虚/白边 | 用软 Alpha 抠图（BiRefNet）分离处理，别让生成模型抠 |
| 整组图色调不一致 | 提示词无法解决 → 用参考图驱动的批量调色 + ΔE00 质检 |
| 手指/耳朵崩坏 | 让 mask 避开手部；或提示"双手自然放置，不要改变手部" |
| 文字/logo 变形 | 用 mask 保护该区域；或后期用确定性方式贴回 |

## 七、工程化建议

1. **把提示词做成模板 + 变量**，而不是每次手写。
   - 模板固定「动作 + 保留清单 + 反向约束」三段
   - 变量只替换场景相关的部分（部位、风格、程度）
2. **每个场景配一个"保留清单"常量**，所有请求自动追加。这比每次手写可靠得多。
3. **把 degree（程度）做成可选档位**：轻 / 中 / 重，映射到提示词措辞**和** denoise 参数。
4. **多轮拆分由系统编排**，而不是让模型一次完成。每轮结果可质检、可回退。
5. **保留 seed 与参数记录**，便于复现和批量统一。
