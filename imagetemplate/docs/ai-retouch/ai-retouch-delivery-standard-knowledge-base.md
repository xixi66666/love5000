# AI 修图副业：交付标准与提示词体系知识基础

> **标注约定**：**【核实】**=有官方/可访问来源，附 URL；**【推断】**=行业经验判断，需实测；**【待核】**=硬规格但来源不足，**需按当地最新规定核实**。
> 本文档所有尺寸/像素规格在上线前必须来自受理机构或平台后台的当日页面。

## 一、总判断：AI 能替代什么

| 层级 | 含义 | 场景 |
|---|---|---|
| **A 类：AI 可独立产出** | 客户不要求"这是本人实拍" | 电商产品图/场景图/详情页、宠物摄影、老照片上色与放大、遗像翻新、年会合影换背景统一色调、写真/婚纱的**概念样片与风格小样** |
| **B 类：必须实拍底片 + AI 后期** | 客户要"像我" | 证件照（换底色/裁切）、形象照、个人写真成品、婚纱照成品、孕妇/儿童/亲子/全家福、毕业照、活动跟拍 |
| **C 类：不可靠或合规风险高** | 不要作为主卖点 | 证件照**直接生成人脸**、真人身份克隆、遗像改表情、未成年人形象商业化 |

**为什么 B 类是主战场**【核实】：官方证件照明确要求"不得对照片进行修改，不得使用合成照片"；多地报名系统已明确禁用"海马体照片"（精修证件照），原因是"P 图过度、面部特征失真导致审核不通过"（[中国之声](https://news.cnr.cn/native/gd/kx/20241106/t20241106_526966245.shtml)）。**证件照业务的价值在"合规裁切+换底色"，不在"美颜"。**

**常见失败点**：头发遮挡眉毛/耳朵、镜片反光、头部倾斜侧身、背景有阴影、头顶留白不足、P 图过度致人脸识别不过。**AI 只应做**：抠图换底、按规格裁切头部比例、明暗与色偏校正、去污点与衣物褶皱；**绝不可重塑五官**。

## 三、AI 可行性与提示词结构

### 3.1 场景 → 实现路径

| 场景 | 路径 | 关键约束 |
|---|---|---|
| 证件照 | **实拍 + 规则化处理** | 禁止生成人脸、禁止磨皮改变五官 |
| 形象照 | 实拍 + 指令式编辑（保身份） | 只调光影与皮肤，不动骨相 |
| 写真/婚纱 | 实拍 + AI 批量调色/换天/修瑕疵；样片可文生图 | 整组色调锁死为同一组参数 |
| 儿童/亲子/全家福 | 实拍 + 换脸合成（多张优选表情） | 换脸后须统一肤色与光线方向 |
| 电商产品/模特 | **可文生图**（产品图最好实拍+场景合成） | 产品本体不得被重绘（会改 logo/文字） |
| 老照片修复/上色 | AI 独立 | 上色须与客户确认年代色系，不"脑补"五官 |
| 遗像 | AI 修复 + 翻新 | 不主动营销，只做技术交付 |

### 3.2 通用提示词骨架（六段式）

```
【主体】年龄/性别/发型/服装/姿态/表情，越具体越好
【光线】光位 + 光质 + 光比，如：蝴蝶光主光 + 右侧柔光箱补光，光比 1:3
【镜头】焦段 + 光圈 + 机位，如：85mm f/1.4，平视，半身构图
【景深与背景】虚化程度 + 背景内容，如：f/1.8 浅景深，纯色灰幕轻微虚化
【色调与质感】胶片/色系 + 皮肤质感，如：Portra 400 色调，低对比奶油肌，保留毛孔与绒毛
【负面约束】塑料皮肤、过度磨皮、五官变形、多指、文字水印、HDR 过曝、卡通化
```

## 四、可复制提示词模板

**① 商务形象照（实拍精修，保身份）**
```
基于原图精修，保持人物五官、脸型、发际线、痣与疤痕完全不变。
仅做：统一光线为伦勃朗光，背景压暗至中性灰，提亮眼神光，保留毛孔与细纹，
去除临时痘印，牙齿自然增白，抚平西装褶皱。输出 85mm f/2 质感，浅景深，半身居中，sRGB。
不要改变：脸型（不得瘦脸）、肤色色相、发型轮廓、五官比例、衣物颜色。
不要：塑料皮肤、磨皮过度、HDR 过曝、AI 美化。
```

## 五、图像编辑模型提示词工程（2026）

### 5.1 编辑提示 ≠ 文生图提示

文生图要"从零描述整个世界"；编辑模型要**只描述"要改的那部分"**并显式声明其余不变。编辑模型已以原图为条件，冗余描述会被解读为"重新生成整张图"，从而引发身份漂移。三条实操原则【推断，据各模型文档与社区实践归纳】：
1. **动作动词开头**：`Change / Replace / Remove / Add / Keep`，一句话一个动作。
2. **不复述全局风格**：不要重写"这是一张 85mm 拍摄的……"——那是在要求重绘。
3. **以"不要改变清单"收口**：防漂移最有效的单一手段。

### 5.2 "只改 X"句式库（可直接复制）

| 中文 | 英文 |
|---|---|
| 只修改 X，其余保持与原图完全一致。 | Change only X. Keep everything else exactly the same as the original. |
| 保持人物身份、姿势、光线和背景不变。 | Preserve the subject's identity, pose, lighting, and background unchanged. |
| 不要改变脸部结构、五官比例或肤色。 | Do not alter facial structure, feature proportions, or skin tone. |
| 仅替换背景，主体边缘、发丝与阴影保持原样。 | Replace only the background; keep the subject's edges, hair strands, and shadows intact. |
| 保持构图、机位和画幅比例不变。 | Maintain the original composition, camera angle, and aspect ratio. |
| 除上述修改外，输出须与原图像素级一致。 | Apart from the described edit, the output must match the input pixel-for-pixel. |
| 不要重新生成整张图片。 | Do not regenerate the whole image. |
| 保持文字、logo 和产品细节完全不变。 | Keep all text, logos, and product details unchanged. |
| 非目标区域请勿美化或重绘。 | Do not beautify or repaint any area outside the target region. |
| 仅调整亮度与色温，不改动内容。 | Adjust only brightness and color temperature; do not change content. |

### 5.3 多轮迭代策略

1. **一轮一件事**：修瑕疵 → 调光 → 调色 → 裁切。合并动作会稀释每项执行强度。
2. **基于上一轮输出继续**，不要每轮从原图重来。
3. **第 3 轮仍漂移则回退原图重写提示词**，累积漂移不可逆。
4. **锁定锚点**：每轮复述同一段"不要改变清单"，把它当常量而非一次性说明。
5. **先锁后改**：先出一张"仅确认身份未变"的中转图，确认后再做风格化。

### 5.4 防过度修改三招

- **清单化否定**：逐条列出"不要变"的具体项（脸型/痣/疤痕/眼镜/发型/衣物 logo），远胜笼统的"保持原样"。
- **局部化**：能用蒙版/局部重绘就不做全图编辑；全图编辑的默认行为是"重新解释整张画面"。
- **锚定特征**：主动写出 3–5 个识别特征（"左眉尾有疤、鼻梁右侧有痣、黑框方形眼镜"），模型会视为不可变项。

### 5.5 常见失败 → 修复句式

| 症状 | 修复提示词 |
|---|---|
| 脸变了/不像本人 | 保持面部特征与参考图完全一致：脸型、眼距、鼻型、唇形、痣的位置；仅允许调整光线与皮肤质感。 |
| 肤色不一致 | 将所有人物的肤色统一到同一白平衡与色温；以画面中央人物为基准，其余人物匹配之。 |
| 背景被意外改动 | 背景保持原图不变；仅修改主体。 |
| 风格化过重 | 降低风格化强度至接近写实摄影；保留原始色彩关系，不做艺术化重绘。 |
| 文字/水印错乱 | 不要生成任何文字、字母、数字或水印；如原图有文字，保持其原始内容与字体不变。 |
| 手部畸形 | 双手自然放松，五指结构正确，不新增肢体。 |

## 六、客户沟通与验收

### 6.1 返工 Top 原因

1. **风格方向未对齐**——客户说"感觉不对"却说不清。【核实，[像素蛋糕 wiki](https://wiki.pixcakeai.com/efficiency-tools/10930.html)】该来源明确指出：多数返工"不是修图师做不到，而是双方对'好看'的定义从一开始就不一样"，**方向没对齐时修多少轮都是白修**。
2. 不像本人（液化过度、磨皮丢失特征）。3. 太假（塑料皮肤、高频缺失）。4. 肤色偏黄/偏红（白平衡与相机配置文件不匹配）。5. 背景换得不自然（边缘、阴影方向、透视三者不一致）。6. 整组色调不统一。7. 精修张数与预期不符。8. 交付尺寸/格式被平台驳回。9. **意见经销售→选片→修图多次转述而失真**【核实，同上】。10. 完成标准在过程中不断变化【核实，[同站](https://wiki.pixcakeai.com/efficiency-tools/10383.html)】。

### 6.2 标准流程与话术

**流程**：需求沟通表 → 3 张风格小样确认 → 批量精修 → 2 轮免费修改 → 交付 → 尾款。
**修改轮次**：小样阶段**不限次**直到风格确认；精修交付后 **2 轮免费**，第 3 轮起按张计费。【推断，行业惯例】
**定金**：签约 30%–50%，交付前结清尾款；源文件（PSD/RAW）通常不随交付提供。【推断】

> **风格确认**：「为确保一次做对，我先免费出 3 张不同方向的小样（原图质感／通透奶油肌／胶片暖调），您选定后我再批量处理。批量开始后换方向等于重做一轮。」
>
> **返工界定**：「免费修改含：色调微调、瑕疵遗漏、液化程度。不含：更换风格方向、增加修图张数、原片本身的光线问题。」
>
> **"不像我"应答**：「我理解您担心失真。请确认两点：① 是脸型削太多，还是皮肤太光滑？② 能否圈出您觉得最像的一张原片？我以那张的特征为基准回调，还原脸型与皮肤纹理，光影保留。」

### 6.3 AI 出小样流程【推断，结合本仓库能力】

1. **低分辨率草稿** 512–1024px，**带水印**，防未付费使用。
2. **多方案并列**：同图一次出 3 个方向（A/B/C），让客户"选"而非"描述"。
3. **先锁风格再批量**：选定后固化提示词与参数为**整组统一设置**，批量跑完再逐张人工质检。
4. **小样即验收基线**：确认后写入合同附件，作为后续返工判定依据。

### 6.4 结构化修改申请单

| 字段 | 填写要求 |
|---|---|
| 图片编号 | 精确到文件名 |
| 问题类型 | 下拉：肤色／磨皮程度／脸型／背景／色调／瑕疵遗漏 |
| 期望效果 | 一句话 + **必附参考图** |
| 修改范围 | 仅此张／整组（整组须说明判定标准） |
| 优先级 | 加急／正常 |

**为何有效**：把"感觉不对"强制转译为六类可执行问题，消除转述失真；"必附参考图"把主观感受变成可对齐的视觉锚点。【核实支撑，[像素蛋糕 wiki](https://wiki.pixcakeai.com/efficiency-tools/10930.html) 建议"必须用参考图做锚定，不能只靠口头描述"】

### 6.5 合规与伦理红线

- **证件照**：不得用 AI 改变五官。官方要求"不得对照片进行修改，不得使用合成照片"，报名系统会因"面部特征失真"驳回。【核实，[中国之声](https://news.cnr.cn/native/gd/kx/20241106/t20241106_526966245.shtml)】
- **肖像权**：需客户书面授权，明确用途与期限；商用图尤其必要。
- **未成年人**：需监护人书面同意，不得用于商业化形象推广。
- **遗像业务**：**不主动营销、不做推广触达**，仅在被询问时响应；只做修复、翻新、背景与色调处理，**不得改变表情、姿态或增删人物**；常用 12 寸或 16 寸输出，沟通须克制、不加表情符号、不催促。【推断，伦理惯例】
- **AI 披露**：电商与广告场景下，改变产品外观或人物形象须评估平台 AI 标识要求。

## 七、落地优先级

1. **先做 A 类中规则最清晰的**：老照片修复、电商白底/场景图、合影统一色调——验收客观、返工可控。
2. **再做证件照**：规格硬但流程标准化，适合走量；定位"合规、快速、可批量"，**不做美颜**。
3. **人像精修走"实拍 + AI 辅助"**：提示词只用于调光、调色、去瑕疵；液化与熔接保留人工判断。
4. **暂不承诺**：婚纱照全流程替代、遗像生成、真人身份克隆。
