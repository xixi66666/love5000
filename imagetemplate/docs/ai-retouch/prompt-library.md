# AI 修图提示词库（可直接复制使用）

> 本文件是**开箱即用**的提示词库，服务于影楼替代与电商场景。
> 配套方法论见 [prompt-engineering.md](prompt-engineering.md)，交付规格见 [ai-retouch-delivery-standard-knowledge-base.md](ai-retouch-delivery-standard-knowledge-base.md)。
>
> **使用前须知**：标「文生图」的模板可直接生成；标「编辑」的模板需要**上传原图**使用，
> 且必须遵守一条铁律——**修图用「只改 X + 保留清单」，不要堆风格词**，否则模型会整图重绘，必然违和。

---

## 第一部分：完整场景模板

### 模板 1 · 商务形象照（编辑 · 保身份）

用于：职业照、商务头像、领英头像。
核心：**只调光影与皮肤，绝不动骨相。**

```
基于原图精修，保持人物五官、脸型、发际线、痣与疤痕完全不变。

只做以下调整：
- 统一光线为伦勃朗光（暗侧脸颊形成三角光斑）
- 背景压暗至中性灰
- 提亮眼神光
- 保留毛孔与细纹的皮肤质感
- 去除临时痘印（不要磨皮）
- 牙齿自然增白
- 抚平西装褶皱

输出质感：85mm f/2，浅景深，半身居中，sRGB。

不要改变：脸型（不得瘦脸）、肤色色相、发型轮廓、五官比例、衣物颜色。
避免：塑料皮肤、过度磨皮、HDR 过曝、AI 美化。
```

### 模板 2 · 日系胶片写真（文生图 · 可作小样）

用于：写真样片、风格小样（给客户选方向）。
核心：胶片型号 + 光位 + 皮肤质感三个要素必须同时写。

```
一位 25 岁东亚女性，浅米色针织衫，自然妆容，窗边侧身回望，神情松弛。

光线：大面积窗光柔光，左侧白色反光板补光，光比 1:4。
镜头：85mm f/1.8，平视，半身构图，头顶留白约 1/6。
色调：Fuji Pro 400H 胶片模拟，青绿冷调，低饱和，轻微颗粒。
皮肤：保留毛孔、绒毛与自然油光，次表面散射通透感，不磨皮。
构图：三分法，人物居右三分之一，左侧留白。

避免：塑料皮肤、过度磨皮、五官变形、多指、文字、水印、卡通化、过曝。
```

### 模板 3 · 古风写真（文生图 · 可作小样）

```
身着宋制褙子的年轻女性，立于园林回廊，手持团扇，垂眸浅笑。

光线：午后侧逆光，竹影投于墙面，暖调轮廓光勾发丝。
镜头：135mm f/2，半身偏全身，机位略低。
色调：低饱和青绿与藕荷色，宣纸质感，轻微颗粒。
皮肤：细腻有纹理，无油光，唇色自然殷红，不假面。
构图：回廊立柱形成框架构图，人物居左，右侧留白。

避免：现代物件、塑料皮肤、过度磨皮、韩式浓妆、表情夸张、水印。
```

### 模板 4 · 电商白底模特图（文生图 / 编辑）

用于：服装模特图、白底主图。
核心：**产品本体（版型/颜色/材质/logo）必须完全一致，不得重绘。**

```
女性模特穿着 <商品名称>，正面站立，双手自然下垂，直视镜头，轻微微笑。

光线：左右双柔光箱均匀布光，无硬阴影，背景纯白 RGB(255,255,255)。
镜头：50mm f/5.6，全身构图，主体占画面 75%，居中，四边留白均等。
色调：中性白平衡，色彩还原真实，不做风格化调色。

要求：服装版型、颜色、材质纹理、logo 与 <商品名称> 完全一致，不得重绘。

避免：背景非纯白、硬阴影、色偏、改变服装颜色/版型、添加配饰、文字水印。
```

> ⚠️ 白底图更稳的做法：**先用 BiRefNet 类模型抠图 + 纯白合成，再用生成模型做场景**。
> 让生成模型抠图会得到发虚的边缘和灰边，平台会判定"抠图贴图感明显"而拦截。

### 模板 5 · 婚纱内景（文生图 / 编辑）

```
一对新人相拥而立，新娘白色缎面婚纱，新郎黑色西装，深情对视。

光线：主光左前 45° 大柔光箱，右侧反光板补光，背景纱幔轻微虚化。
镜头：85mm f/1.8，中景，机位平视。
色调：Kodak Portra 400 暖调，白纱保持纯白不灰，肤色红润通透。
皮肤：双人肤色统一，保留皮肤纹理，不磨皮成蜡像。
构图：人物居中偏右，顶部留白 1/5 供排版文字。

避免：白纱发灰、双人肤色不一致、塑料皮肤、五官互换、多指、水印。
```

> ⚠️ **婚纱照严禁整图重绘**。这是客户投诉"假"的重灾区。成品必须走"实拍底片 + 调色 + 局部精修"。

## 第二部分：修图「保留清单」句式库（最高频复用）

这是修图提示词里**性价比最高的一句话**。显式列出"不要改"比只说"改什么"有效得多。

### 通用保留清单（每次修图都追加这段）
```
保持以下内容完全不变：
- 五官形状、脸型轮廓、眼睛大小与瞳孔位置
- 肤色与肤质纹理（毛孔、绒毛）
- 发型、发际线、发丝走向
- 光影方向、明暗对比、阴影位置
- 背景、构图、服装、配饰
- 画面整体的色温与色调
不要重新生成整张图片，只修改上述指定区域。
```

### 中英对照句式（可直接粘贴）

| 中文 | 英文 |
|---|---|
| 只修改 X，其余保持与原图完全一致。 | Change only X. Keep everything else exactly the same as the original. |
| 保持人物身份、姿势、光线和背景不变。 | Preserve the subject's identity, pose, lighting, and background unchanged. |
| 不要改变脸部结构、五官比例或肤色。 | Do not alter facial structure, feature proportions, or skin tone. |
| 仅替换背景，主体边缘、发丝与阴影保持原样。 | Replace only the background; keep the subject's edges, hair strands, and shadows intact. |
| 保持构图、机位和画幅比例不变。 | Maintain the original composition, camera angle, and aspect ratio. |
| 除上述修改外，输出须与原图像素级一致。 | Apart from the described edit, the output must match the input pixel-for-pixel. |
| 不要重新生成整张图片。 | Do not regenerate the whole image. |
| 保持文字、logo 和产品细节完全不变。 | Keep all text, logos, and product details unchanged. |
| 非目标区域请勿美化或重绘。 | Do not beautify or repaint any area outside the target region. |
| 仅调整亮度与色温，不改动内容。 | Adjust only brightness and color temperature; do not change content. |

### 防身份漂移（人像必加）
```
这是一张真实人物的照片，请严格保持人物的身份特征：
- 保留其独特的面部比例与骨相，不要美化成通用模板脸
- 不要改变眼睛形状、鼻型、唇形、下颌线
- 目标是"同一人更好看的状态"，不是"另一个人"
```

### 反向约束（通用负面清单）
```
避免：过度磨皮、塑料感、蜡像感、过度锐化、HDR感、过度饱和、
对称性过强、AI感、面部结构改变、多余的手指或肢体、文字乱码、饰品结构错误。
```

## 第三部分：分场景修图指令（短指令版）

适合配合 mask 使用，或作为多轮迭代的单步指令。

| 场景 | 提示词 |
|---|---|
| 祛痘 | 只去除面部明显痘印、红点和斑点。保留皮肤真实的毛孔纹理与质感。不要磨皮，不要改变肤色。 |
| 去眼袋 | 轻微减淡眼下黑眼圈，保留卧蚕与眼袋的自然结构。不要改变眼型。 |
| 去皱纹 | 轻微减弱法令纹与眼周细纹，程度要轻。保留皮肤纹理，不要磨皮。 |
| 换背景 | 把背景替换为<描述>。保留发丝细节与半透明边缘，不要硬边或白边。新背景光线方向需与人物原光线一致（主光来自<左/右/正>上方）。 |
| 换装 | 把<部位>更换为<描述>。服装版型贴合原有体型并自然产生褶皱。保持面部、发型、姿态、双手位置不变。 |
| 去杂物 | 移除画面中的<物体>。用周围的背景自然填补，保持纹理与光影连续。不要改变其他任何内容。 |
| 老照片修复 | 修复划痕、折痕、霉斑。轻微提升清晰度，不要过度锐化。保留原片颗粒感与年代质感，不要美化成现代审美。 |
| 老照片上色 | 为黑白照片上色。肤色用符合年代的自然色调，不要过白。服装与背景参考<年代>常见配色，低饱和。保留颗粒质感与光影关系。 |
| 证件照换底 | 背景替换为纯<白/蓝/红>色，颜色均匀无渐变。人物居中，头部占画面约 2/3，头顶留适当空白。严格保持五官形状与比例，禁止瘦脸、放大眼睛、改五官。 |
| 统一色调 | 将本组照片的肤色与色调统一到与参考图一致的<暖/冷>调。只调整色彩与明暗，不改动任何内容与结构。 |

## 第五部分：常见失败 → 修复提示词

出现问题时，直接把对应修复句追加到下一轮。

| 症状 | 修复提示词 |
|---|---|
| 脸变了 / 不像本人 | 保持面部特征与参考图完全一致：脸型、眼距、鼻型、唇形、痣的位置；仅允许调整光线与皮肤质感。 |
| 肤色不一致（多人或整组） | 将所有人物的肤色统一到同一白平衡与色温；以画面中央人物为基准，其余人物匹配之。 |
| 背景被意外改动 | 背景保持原图不变；仅修改主体。 |
| 风格化过重 | 降低风格化强度至接近写实摄影；保留原始色彩关系，不做艺术化重绘。 |
| 文字 / 水印错乱 | 不要生成任何文字、字母、数字或水印；如原图有文字，保持其原始内容与字体不变。 |
| 手部畸形 | 双手自然放松，五指结构正确，不新增肢体。 |
| 皮肤太塑料 | 恢复皮肤高频纹理：毛孔、绒毛与自然油光；降低磨皮强度；保留微小的皮肤瑕疵。 |
| 边缘发虚 / 白边 | 保留发丝的细节与半透明过渡；边缘不要产生光晕或白边。 |

## 第六部分：多轮迭代编排（推荐做法）

不要试图一句话完成复杂修图。**拆成串行的小步骤，每步只做一件事。**

```
第1轮：只去除痘印和斑点，其余完全不动
第2轮：在此基础上，轻微减弱眼袋，程度轻，不要改变眼型
第3轮：背景换成纯净浅灰色，人物边缘自然，发丝保留
第4轮：整体统一到参考图的暖色调
```

**规则**：
1. **一轮一件事** —— 合并动作会稀释每项执行强度。
2. **基于上一轮输出继续** —— 不要每轮从原图重来。
3. **第 3 轮仍漂移就回退原图重写提示词** —— 累积漂移不可逆。
4. **每轮复述同一段保留清单** —— 把它当常量，不是一次性说明。
5. **先锁后改** —— 先出一张"仅确认身份未变"的中转图，确认后再做风格化。

## 第七部分：客观验收（别靠肉眼争论）

修图完成后，用 `ImageQualityMetricsService` 跑质检（见项目源码）：

| 指标 | 阈值 | 超标含义 |
|---|---|---|
| **纹理保留率** | < 0.75 | 疑似过度磨皮，皮肤会塑料化 |
| 结构保持度 | < 0.9 | 疑似结构漂移，五官被改动 |
| 亮度偏移 | > 8 | 曝光漂移，组图不一致 |
| 肤色色差 | > 5 | 肤色漂移，交付级事故 |

**验收要点**：一定要在**交付尺寸**下看，不要只在 100% 放大的大屏上看。
Retouch4me 明确说这一步能挡掉大多数"过度修图"投诉。
