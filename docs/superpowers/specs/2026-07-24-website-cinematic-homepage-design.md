# Website 电影化服务主页设计

## 目标

把 `website` 首页改造成单视口、沉浸式的电影化服务入口，同时保留现有 8 个服务跳转、跨端口健康检测、图片模板登录保护和站点登录/注册能力。

## 视觉方向

- 以用户提供的四段全屏循环视频为背景，使用 1000ms 交叉淡入淡出。
- 叠加指定透明 PNG、暗角和轻量颗粒，形成层次但不遮挡正文。
- 使用 Instrument Serif 承担品牌和大标题，正文、按钮、状态使用系统字体。
- 导航、操作按钮、服务入口和登录弹窗使用统一的液态玻璃语言。
- 继承 Apple 设计系统的克制层级、紧凑导航、全屏摄影和明确的胶囊形操作语法，不复制品牌标识。

## 页面结构

1. 固定全屏背景层：四段视频、透明 PNG、暗角和降级背景。
2. 顶部导航：品牌、站内链接、登录/注册；移动端切换为汉堡菜单。
3. 中央 Hero：状态徽章、中文主标题、说明、服务入口主按钮和四场景切换器。
4. 底部服务 Dock：8 个服务入口，展示名称、端口与实时状态；窄屏横向滚动。
5. 登录弹窗：沿用现有 `/api/auth/**` 数据流，并保护图片模板入口。

## 交互与状态

- 视频默认选择第一段。切换时锁定 1000ms，避免快速点击造成竞态。
- 第三段 Deep Woods 激活时，仅 Hero 正文切换为 `#182c41`；导航和服务 Dock 始终保持白色。
- 移动菜单使用 500ms 分段入场，支持 Escape 关闭并锁定背景滚动。
- 健康检测初始立即执行，之后每 30 秒刷新；状态分为检测中、在线、离线。
- 视频或远程覆盖图加载失败时保留黑色和径向光晕降级背景。
- `prefers-reduced-motion` 下停止覆盖层漂浮、关闭平滑动画，并暂停非当前视频。

## 响应式与可访问性

- 桌面展示完整导航和底部横向服务 Dock。
- 平板和手机使用汉堡菜单；服务 Dock 保持可横向滚动和可键盘聚焦。
- 所有交互控件至少 44px，提供可见焦点、语义化标签、跳转链接和状态文本。
- 采用 `100svh` 并提供 `100vh` 降级，确保移动浏览器地址栏变化时不产生额外页面滚动。

## 验证

- 静态资源测试断言四段视频、四个场景、8 个服务、健康检测属性、移动菜单和鉴权入口均存在。
- Maven `website` 模块测试验证 Spring 上下文和静态资源。
- 浏览器分别验证桌面与移动视口、视频切换、第三场景配色、移动菜单、服务状态与登录弹窗。
