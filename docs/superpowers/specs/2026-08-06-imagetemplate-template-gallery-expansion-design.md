# ImageTemplate 模板选择区扩展设计

## 背景

`imagetemplate` 首页的“灵感大厅”采用左右分栏。左侧大幅介绍和右侧多行筛选占用了较多首屏空间，模板列表只能在较小的嵌套滚动区域中展示，用户浏览和选择模板时视野受限。

## 目标

- 让模板浏览和选择成为“灵感大厅”的首要任务。
- 在常见 `1920x1080` 桌面视口中舒适展示 3 至 4 列、至少 2 行模板。
- 保留现有黑金视觉风格、搜索、功能分类、场景筛选、高级筛选、加载更多及四场景状态。
- 移动端保持单列卡片和自然滚动，避免横向溢出或文字遮挡。

## 设计方案

### 页面结构

桌面端将原有左侧介绍区压缩为展廊上方的横向标题栏。标题、简短说明、模板总量和“解构已选模板”操作集中在该区域，不再占用整列宽度。

模板展廊占据场景主体的完整宽度和大部分可用高度。模板列表继续在展廊内部滚动，保证底部场景 Dock 固定且不影响其他场景。

### 筛选区

搜索框和主要开关维持清晰可见。一级功能分类由多行网格改为单行横向滚动，二级场景沿用横向滚动，从而减少筛选区的垂直高度。高级筛选继续默认收起。

所有现有筛选状态、请求参数和 300ms 搜索防抖保持不变，本次不修改 API 或数据模型。

### 模板栅格

模板卡片保持现有内容层级和点击行为。桌面端根据可用宽度自适应为 3 至 4 列，中等宽度为 2 至 3 列，移动端为 1 列。卡片尺寸设置稳定的最小高度，加载、选中和悬停状态不能引起布局跳动。

### 响应式行为

- 宽屏桌面：紧凑标题栏、全宽展廊、4 列模板。
- 普通桌面和小型笔记本：全宽展廊、2 至 3 列模板，筛选条可横向滚动。
- 平板和手机：标题信息进一步精简，面板使用自然页面滚动，模板单列显示。

## 边界与风险

- 不修改“模板解构”“Prompt 编导台”“图片生成舱”的结构和行为。
- 不改变模板分页数量、接口参数或选中模板状态。
- 需要重点验证固定顶部栏和底部 Dock 下的可用高度，避免模板列表出现无法触达的末尾内容。
- 横向筛选条必须支持键盘焦点和触控滚动，并保留可见的选中状态。

## 验证

- 运行现有静态资源测试和 `imagetemplate` 模块测试。
- 在 `1920x1080`、`1366x768`、`900x900` 和手机视口检查模板可见数量、滚动、筛选和文字溢出。
- 点击不同模板，确认仍能进入“模板解构”，并且返回后筛选与选中状态不丢失。
- 检查控制台错误、横向页面溢出及 `prefers-reduced-motion` 降级。
