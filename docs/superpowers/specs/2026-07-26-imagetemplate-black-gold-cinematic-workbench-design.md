# Imagetemplate 黑金电影化工作台设计

## 目标

将 `imagetemplate` 当前的工具型双栏页面改造成与 `website` 动态主页一致的电影化单视口体验，同时完整保留模板检索、模板详情、变量填写、Prompt 渲染、参考图上传、图片参数配置和 OpenAI 图片生成能力。

本次只改造 `imagetemplate` 前端展示与交互编排，不修改现有后端 API、图片尺寸规则、鉴权方式或生成请求结构。

## 设计选择

采用“黑金艺术画廊 + 四场景单视口”方案：

1. 灵感大厅：发现、搜索和筛选模板。
2. 模板解构：查看选中模板的说明、结构化 JSON 和原始 Prompt。
3. Prompt 编导台：填写变量、补充要求并预览最终 Prompt。
4. 图片生成舱：配置 API Key、参考图、尺寸与生成参数，展示生成结果。

桌面端以单视口场景切换为主；移动端允许场景内部自然滚动，避免长表单被视口高度限制。

## 视觉方向

- 主色为墨黑、炭灰和香槟金，少量暖白用于正文。
- 背景使用纯 CSS 动态光幕、金色流线、颗粒和暗角，不依赖外部视频、图片或新前端框架。
- 卡片使用低透明度深色玻璃、细金边和局部高光，形成展柜与画框层次。
- 标题采用高对比度的编辑式大字排版；表单、参数和状态使用清晰的系统字体。
- 动效包括背景缓慢漂移、场景淡入位移、卡片聚焦和按钮光泽扫过；不使用影响填写稳定性的持续缩放。
- `prefers-reduced-motion` 下关闭背景漂移、扫光和大幅场景位移，仅保留必要的状态切换。

## 页面结构

### 固定舞台

- 全屏背景层：黑金渐变、光晕、流线、噪点和暗角。
- 顶部品牌栏：服务名称、当前场景名称、接口状态提示和返回主页入口。
- 中央视口：一次呈现一个场景，切换时使用可中断的淡入淡出。
- 底部液态玻璃 Dock：四个场景入口、当前步骤进度、上一幕和下一幕操作。
- 全局反馈层：加载、错误、成功和生成进度提示。

### 场景一：灵感大厅

- 首屏标题说明图片模板工作台的用途。
- 搜索框和分类筛选固定在模板展廊上方。
- 模板列表改为横向画廊卡片，卡片展示名称、分类、简介和选中状态。
- 点击模板只更新当前选择；“解构此模板”按钮进入第二场景，避免误触后强制跳转。
- 无搜索结果时展示明确空状态，并提供清除筛选操作。

### 场景二：模板解构

- 左侧为模板标题、简介和适用场景。
- 右侧以可切换的“原始 Prompt / 模板 JSON”展柜展示现有数据。
- 提供复制操作和“进入编导台”主按钮。
- 未选择模板时，引导用户返回灵感大厅。

### 场景三：Prompt 编导台

- 根据模板变量动态生成字段，保留现有字段标识与渲染逻辑。
- 附加要求单独作为“导演备注”区域。
- 最终 Prompt 使用可滚动预览区，输入变化后沿用现有渲染节奏更新。
- 校验错误定位到对应字段，同时在场景顶部显示简短汇总。
- 提供返回模板解构和进入图片生成舱的操作。

### 场景四：图片生成舱

- 第一组为 API Key 和参考图片。
- 第二组为尺寸、质量、格式、背景等生成参数。
- 尺寸继续使用前后端一致的合法性规则，并保留 2K/4K 实验尺寸提示。
- 生成按钮在请求期间显示进度并防止重复提交。
- 结果区支持占位、加载、成功图片和失败提示四种状态。
- 生成成功后不自动离开当前场景，便于用户调整参数继续生成。

## 状态与数据流

- 现有模板 API 和图片生成 API 保持不变。
- JavaScript 使用单一 `activeScene` 状态控制场景和 Dock；模板、变量、参数与生成结果仍沿用当前数据模型。
- 场景切换不清空用户已经填写的变量、API Key、参考图或生成参数。
- 浏览器前进后退不承担场景路由职责，避免引入新的 URL 兼容负担。
- API Key 继续只保存在当前浏览器会话中，不写入 HTML、日志或持久化存储。
- 场景切换动画期间仍允许用户点击其他场景；实现以最后一次选择为准，避免锁死界面。

## 错误处理

- 模板列表加载失败：在灵感大厅展示重试入口。
- 模板详情或 Prompt 渲染失败：保留当前输入并显示就地错误，不退回第一场景。
- 图片参数非法：前端阻止请求并指出具体规则。
- 图片生成失败：保留所有表单数据、参考图预览和最终 Prompt，允许直接重试。
- 背景动效不可用：自动退化为静态黑金渐变，不影响功能。

## 响应式与可访问性

- 桌面端使用四场景单视口，内容区域按场景独立滚动。
- 平板和手机保持相同四场景导航，Dock 支持横向滚动，表单改为单列。
- 交互控件最小点击区域为 `44px`，提供可见焦点和键盘操作。
- 场景容器使用语义化标题，切换后将焦点移动到场景标题，并通过无障碍状态文本提示。
- 金色仅用于强调，不作为唯一的状态区分方式；错误、成功和加载同时提供图形或文本。

## 实现边界

- 继续使用原生 HTML、CSS 和 JavaScript，不引入 React、Tailwind、Framer Motion 或构建链。
- 优先保留现有 DOM `id` 和接口调用函数；需要调整结构时同步更新静态资源测试。
- 不修改 Java Controller、Service、模板 JSON 数据和 OpenAI 配置。
- 不添加外部字体、视频、图片 CDN 或运行时第三方脚本。
- 同步更新根 `AGENTS.md`、根 `README.md`、`imagetemplate/AGENTS.md` 和 `imagetemplate/README.md` 中的页面说明。

## 验收标准

- 四个场景及底部 Dock 均可通过鼠标和键盘切换。
- 搜索、分类、模板选择、详情查看、变量填写、Prompt 渲染和图片生成行为与改造前一致。
- 场景切换不会丢失表单与生成状态。
- 合法和非法图片尺寸继续按既有规则处理。
- 桌面端和移动端没有关键控件溢出或不可达。
- 开启减少动态效果后，所有功能仍可使用。
- `imagetemplate` Maven 测试通过，并增加或更新静态页面结构测试覆盖四场景、Dock 和关键业务控件。
- 浏览器手工验证模板加载、场景切换、Prompt 预览、参数校验和生成失败保留状态。
